# Assets Directory

## Images

This directory contains image assets for the Travel Itinerary AI Agent web application.

### Recommended Images to Add:

1. **hero-banner.jpg** (1920x600px)
   - Beautiful travel montage or world map
   - Used in hero section
   - Suggested: Unsplash travel images

2. **destination-placeholder.jpg** (800x600px)
   - Generic destination image
   - Fallback for destinations without specific images

3. **icons/**
   - activity-icons.svg
   - weather-icons.svg
   - travel-icons.svg

### Free Image Resources:

- **Unsplash**: https://unsplash.com/s/photos/travel
- **Pexels**: https://www.pexels.com/search/travel/
- **Icons8**: https://icons8.com/icons

### Current Setup:

The app uses placeholder URLs from icons8.com for demo purposes.
Replace these with your own images for production use.

### Image Optimization:

- Use WebP format for better compression
- Optimize images before adding (max 500KB)
- Recommended tool: TinyPNG or Squoosh
